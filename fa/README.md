ترجمهٔ خوب باید مانند یک متن فنی فارسیِ تألیفی خوانده شود. لطفاً از ترجمهٔ خودکار و کلمه‌به‌کلمه پرهیز کنید، اصطلاحات را با [واژه‌نامه](TRANSLATION-GUIDE.md) تطبیق دهید و پیوندها و مثال‌های کد را تغییر ندهید.
